# 命令狗的流程（比赛/日常操作手册）

> 一句话：**开视觉 → 开语音 → 说话**。
> 唯一要留神的是电脑 IP 会变，变了先改狗的 `pc_ip.txt`。

---

## 0. 一次性准备（已就绪，不用重做）

| 项 | 位置 | 说明 |
|---|---|---|
| 电脑 IP | 你的电脑 | **动态分配，会变**（现在 = `10.131.255.71`） |
| 狗的 `pc_ip.txt` | 狗 `~/height/pc_ip.txt` | 存电脑 IP，赛段4/6 靠它连视觉主机 |
| 视觉 venv | 电脑 `/home/wjx/cyberdog/ww/vision-venv` | torch+ultralytics+cv2，已装好 |
| 语音节点代码 | 狗 `~/height/voice*.py` 等 | 已部署，已实测 |

---

## 1. 开视觉（电脑上，先开）

```bash
bash /home/wjx/cyberdog/ww/start_vision.sh
# 预期: [LISTEN] :9998 / :9997 / :9999，两个窗口弹出画面
```

> ⚠️ 必须在你**电脑**的终端跑，不要在 ssh 进狗的窗口跑。
> 视觉主机要**先于下令**启动。

---

## 2. 开语音（狗上）

```bash
ssh mi@<狗的IP>
bash ~/height/start_voice.sh
# 预期: voice node up, pid xxx, log: ~/height/logs/voice.log
```

---

## 3. 对狗说话

| 你说（先喊"铁蛋铁蛋"唤醒） | 狗会做什么 |
|---|---|
| 运行第N赛段第一个（N=1/2/3/4） | 从 N 顺序跑到**赛段六**，赛段四虚线在**右**（dash-side=1） |
| 运行第N赛段第二个（N=1/2/3/4） | 同上，赛段四虚线在**左**（dash-side=2） |
| 运行第五赛段 / 运行第六赛段 | 从 5/6 跑到六（不区分第一/第二个） |
| 停止 / 停下 / 结束 | 立即中止当前赛段 |

赛段之间狗会自动站立 10 秒（`stand_idle.py`），用来调整入口。

看执行日志：
```bash
tail -f ~/height/logs/voice.log        # 语音解析/调度
tail -f ~/height/logs/runner.log       # 每个赛段的执行结果
```

---

## 4. 电脑 IP 变了怎么办（最容易踩的坑）

电脑换网/重启路由器后 IP 会变。新 IP 用 `hostname -I` 查（第一个 IPv4）。

```bash
# 在狗上改：
echo 新IP > ~/height/pc_ip.txt
# 或在电脑上改完再传：
echo 新IP > /home/wjx/cyberdog/ww/voice/pc_ip.txt
scp /home/wjx/cyberdog/ww/voice/pc_ip.txt mi@<狗IP>:~/height/pc_ip.txt
```

> **推荐**：赛前给你电脑设**固定 IP**，一次搞定就不用每次改。狗能 ping 通电脑即可
> （`ping <电脑IP>`）。

## 5. 语音失效时的兜底（直接手动跑）

```bash
# 狗上：
python3 ~/height/stage_runner.py --start 2 --side 1     # 从赛段2顺序跑到六，虚线在右
python3 ~/height/stage_runner.py --start 4 --side 2     # 从赛段4跑到六，虚线在左
python3 ~/height/stage_runner.py --stage 1              # 只跑赛段1
# 加 --dry-run 只打印不执行（安全核对）
```

## 6. 收尾

```bash
bash /home/wjx/cyberdog/ww/stop_vision.sh   # 电脑上，停视觉
# 狗上：
kill $(cat ~/height/logs/voice.pid)         # 停语音节点
```

## 7. 相机采集（截图/录像，调试用）—— 狗上跑

调试时把狗看到画面存下来复盘用。工具在狗上 `~/shot/`。**先开相机，再截图/录像。**

### 启动相机
```bash
cd ~/shot && python3 camera_.py
# 依次启动: RealSense(rgb) + 立体(stereo) + AI相机(camera_server)，然后列出 image 话题
```

### 截图（存 1 帧后自动退出）
```bash
cd ~/shot
python3 snapshot_rgb.py      # 前视 RGB  (话题 /image_rgb)
python3 snapshot_ai.py       # AI 相机   (话题 /image)
python3 snapshot_left.py     # 左目      (话题 /image_left)
python3 snapshot_right.py    # 右目      (话题 /image_right)
# 存到 ./snapshots_auto/<话题名>_时间戳.jpg（要先 cd shot，目录在当前目录）
```

### 录像（Ctrl+C 结束才会保存文件）
```bash
cd ~/shot
python3 video_rgb.py         # /image_rgb
python3 video_ai.py          # /image
python3 video_right.py       # /image_right
# 存到 ./videos_auto/<话题名>_时间戳.mp4
```

> ⚠️ 注意：截图/录像的保存目录是**运行命令时的当前目录**（`os.getcwd()`），所以必须先 `cd shot`。
> 截图脚本之间、录像脚本之间**不能同时跑两个**（ROS 节点名相同会冲突）。

把图片/视频拉回电脑：
```bash
scp -r mi@<狗IP>:~/shot/snapshots_auto /home/wjx/cyberdog/ww/
```

## 常见问题

- **语音节点没反应**：先看 `tail -f ~/height/logs/voice.log`，确认节点起来没；狗要联网+绑定小爱账号，命令识别才通。
- **赛段4/6 连接超时**：视觉主机没开，或电脑 IP 变了没同步到狗的 `pc_ip.txt`。先 `ping` 通电脑再跑。
- **狗乱跑想停**：说"铁蛋铁蛋 停止"，或直接 `Ctrl+C`（在狗上跑的执行器窗口按 Ctrl+C 也会中止）。
