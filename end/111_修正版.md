## ⚠️ 提醒

**`stand_idle.py` 缺失**：你本地的 `ww/height/` 里没有 `stand_idle.py`，但 `run_all_stages_dash1.sh` / `dash2.sh` 会调用 `~/height/stand_idle.py`。如果要在机器人上跑全赛段脚本，记得从机器人上取一份，或补一个同名脚本。




以后启动视觉只需：

bash /home/wjx/cyberdog/ww/start_vision.sh    # 启动两个主机
bash /home/wjx/cyberdog/ww/stop_vision.sh     # 停止

狗端启动语音节点（若还没开）：

ssh mi@10.113.209.20
bash ~/height/start_voice.sh
确认电脑 IP 没变（pc_ip.txt = 172.27.135.21；换网就用 hostname -I 查新 IP 改掉）。
对狗说："铁蛋铁蛋 → 运行第N赛段第X个"。赛段之间狗会自动站立 10 秒（stand_idle.py），用来调整入口朝向。
要中途停就说"铁蛋铁蛋 → 停止"；重新下令会直接取代正在跑的任务。
四、执行器内部的容错逻辑
单个赛段失败：默认继续往下跑（和原 bash 无 set -e 一致），结束时汇总"失败赛段"；加 --fail-fast 可任一失败即停。
段间站立：找不到 stand_idle.py 时自动降级为 sleep(10)。
预检：如果本次要跑赛段4/6 但 PC IP 为空，直接拒绝启动，不静默空跑。
中止：停止/新指令 → 对整个进程组发 SIGINT（赛段脚本都自带优雅退出），5 秒不退再 SIGKILL。
